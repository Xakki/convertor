### Backlog: post-MVP форматы конвертации (umbrella, deferred)

**Критичность:** Low

**STATUS: FROZEN** — отложенный бэклог. Карточка-зонтик для конвертаций, заявленных в матрице форматов `ROADMAP.md` (справочные данные), но намеренно вынесенных за рамки MVP. Сюда складываем, чтобы ничего не потерялось; работу не ведём, пока пользователь не разморозит конкретный пункт.

**TAGS:**
- feature
- deferred

**Описание:**
Отложенные возможности конвертации, не входящие в текущий scope валидации воркеров ([[docs-workers-conversion-validation]]). Каждый пункт ниже — отдельный кандидат на будущую карточку при разморозке.

**Проблема / scope:**

#### Архивы (zip/tar/gz/bz2/7z)
- **Что:** перепаковка архивов; `zip, tar, gz, bz2, 7z` → `zip, tar.gz`.
- **Источник:** категория «Архивы» в матрице `ROADMAP.md`.
- **Движок/подход:** Python `zipfile` / `tarfile` / `py7zr`.
- **Почему отложено:** нет владельца-воркера; отдельная категория, не покрытая текущими воркерами.

#### CAD/DWG (dwg/dxf → pdf/svg/png)
- **Что:** конвертация чертежей `dwg, dxf` → `pdf, svg, png`.
- **Источник:** категория «CAD/DWG» в матрице `ROADMAP.md`.
- **Движок/подход:** LibreOffice Draw / `ezdxf`.
- **Почему отложено:** узкая ниша, отдельный движок/тулинг. Примечание: в `workers/tests/example_files/` лежит осиротевшая фикстура `29216306410573.dwg` (без активной реализации).

#### Доп. форматы изображений (SVG/HEIC/AVIF)
- **Что:** входные/выходные форматы изображений `svg`, `heic`, `avif` (матрица заявляет их в категории «Изображения»).
- **Источник:** категория «Изображения» в матрице `ROADMAP.md`.
- **Движок/подход:** требуют доп. библиотек (librsvg / libheif / libavif поверх ImageMagick/Pillow).
- **Почему отложено:** намеренно исключены из image-Dockerfile, чтобы не раздувать образ доп. зависимостями.

#### Разметка rst/latex/wiki (pandoc)
- **Что:** разметка `rst`, `latex`, `wiki` (на входе/выходе) сверх текущих `md`/`html`.
- **Источник:** категория «Разметка» в матрице `ROADMAP.md`.
- **Движок/подход:** Pandoc (уже используется), нужно лишь расширить набор форматов.
- **Почему отложено:** сейчас валидируем только `md`/`html`; остальные форматы разметки вне MVP-scope.

#### MarkItDown (doc → markdown)
- **Что:** альтернативный конвертер doc→markdown на базе `microsoft/markitdown`.
- **Источник:** обсуждение в [[CNV-27-openai-00-integration]]; текущая реализация doc→markdown — на pandoc.
- **Движок/подход:** `microsoft/markitdown` (Python).
- **Почему отложено:** сейчас doc→markdown держим на pandoc; MarkItDown отложен (см. [[CNV-27-openai-00-integration]]).

**Влияние:**
Ширина матрицы форматов `ROADMAP.md` не покрыта полностью; перечисленные конвертации заявлены, но не реализованы. Без этой карточки пункты рискуют потеряться между MVP-scope и матрицей.

**Решение:**
Держать как замороженный бэклог. При возврате к каждому пункту — заводить отдельную todo-карточку с движком/подходом из соответствующей секции выше.

**Критерии приёмки:**
- (на уровне зонтика) Каждый пункт при разморозке выносится в свою карточку и реализуется против матрицы форматов `ROADMAP.md`.
