### Backlog: доп. провайдеры авторизации (Google / GitHub OAuth, deferred)

**Критичность:** Low

**STATUS: FROZEN** — отложенный бэклог. Доп. OAuth-провайдеры запланированы, но не поставлены в график. Карточка существует, чтобы пункт не потерялся.

**TAGS:**
- feature
- deferred

**Описание:**
В `docs/plan.md` (раздел «Другие надёжные сервисы», ~строки 214-215) заявлены доп. провайдеры входа сверх основного метода. Текущая авторизация = Telegram Login Widget + SMS OTP (резерв) — реализовано. Эти OAuth-провайдеры запланированы, но не запланированы по срокам; фиксируем, чтобы не потерять.

**Проблема / scope:**
- **Google OAuth** — вход через Google-аккаунт (`docs/plan.md` ~строка 214).
- **GitHub OAuth** — вход через GitHub-аккаунт (`docs/plan.md` ~строка 215).

**Влияние:**
Без доп. провайдеров охват входа ограничен Telegram + SMS; часть пользователей без Telegram-аккаунта остаётся без удобного метода входа.

**Решение:**
Держать как замороженный бэклог. При разморозке — реализовать через общий OAuth-абстрактный слой Symfony Security (по образцу существующей auth-логики).

**Критерии приёмки:**
- (при разморозке) Каждый провайдер завершает тестовый OAuth-флоу и создаёт/находит User.

**Open questions:**
- MVP или post-MVP? Решить при груминге — нужны ли Google/GitHub OAuth к запуску или после.

**Decisions:**
- Заведено 2026-06-20 по просьбе пользователя — записать отложенные провайдеры авторизации, чтобы не потерять.
