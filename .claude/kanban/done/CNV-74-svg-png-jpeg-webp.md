### Эпик: SVG → PNG, JPEG и WebP; настройки изображений

**Criticality:** High

**TAGS:**
- feature
- images
- svg
- conversion-options

**Description:**
Эпик добавляет востребованный сценарий преобразования векторного SVG в основные
растровые форматы и первый набор управляемых параметров результата для изображений.

**Problem:**
`workers/image/worker.py` поддерживает только нативные для Pillow растровые
источники; SVG исключён из матрицы и из каталога форматов. Пользователь также не
может влиять на размер, качество и фон результата.

**Impact:**
SVG нельзя конвертировать в привычные растровые форматы, а пользователю приходится
получать изображение с единственными серверными настройками.

**Recommendation:**
Сначала добавить безопасную растеризацию SVG через CairoSVG для PNG, JPEG и WebP.
Затем ввести контракт параметров и форму настроек для изображений. Параметры
валидируются API и применяются только воркером, который их поддерживает.

**Acceptance Criteria:**
- Выполнены и прошли проверку CNV-74-01 и CNV-74-02.
- SVG доступен в `/api/v1/formats` и форме только для целевых `png`, `jpg`,
  `jpeg`, `webp`.
- Параметры изображений не меняют поведение остальных категорий конвертации.
- Перед hand-off перезапущен проект, выполнены миграции/импорты при их наличии и
  полный набор проверок проекта.

**Decisions:**
- 2026-08-15: первая поставка SVG ограничена `png`, `jpg/jpeg`, `webp`.
- 2026-08-15: первая поставка настроек изображений — ширина/высота с сохранением
  пропорций, качество JPEG/WebP, фон JPEG и сброс к дефолтам формата.
- 2026-08-15: блок настроек находится под выбором target format, свёрнут по
  умолчанию; предпочтения хранятся в browser-wide `localStorage` по target format,
  без привязки к пользователю.

**Subtasks:**

- CNV-74-02 — Настройки конвертации изображений.
